# Судоку

PWA-судоку среднего уровня в неон-стиле (тёмная navy + циан). Без проигрыша и таймеров: можно пользоваться подсказками, есть светлая/тёмная тема и автосохранение партии.

## Особенности

- Кнопка «Установить приложение» в шапке — PWA работает офлайн.
- Шапка: 📲 установка, ↻ новая игра (с подтверждением), ☀️/☾ тема.
- Вся игра — один файл `index.html` + `icons/`, `manifest.json`, `sw.js`.

## Публикация

GitHub Pages: статический деплой ветки `build` (корень подпапки `/sudoku/`).
