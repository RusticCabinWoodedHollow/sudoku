# Судоку · Дзен ☯

Дзен-судоку среднего уровня сложности. Без проигрыша, без звука,
с бесконечными подсказками, тёмной и светлой темой и автосохранением.
Вся игра — **один файл `index.html`** (~48 КБ), работает офлайн,
устанавливается на Android как приложение (PWA).

## Публикация в GitHub Pages

1. Создайте репозиторий на [github.com](https://github.com) (кнопка **New repository**).
2. Загрузите в него файлы проекта (например, через «uploading an existing file»
   или командой):

   ```bash
   git init
   git add .
   git commit -m "Судоку Дзен"
   git branch -M main
   git remote add origin https://github.com/ВАШ_ЛОГИН/ВАШ_РЕПО.git
   git push -u origin main
   ```

3. В репозитории откройте **Settings → Pages** и в поле **Source** выберите
   **GitHub Actions**.
4. Готово: при каждом `git push` воркфлоу
   [`.github/workflows/deploy.yml`](.github/workflows/deploy.yml) сам собирает
   игру и выкладывает её по адресу

   ```
   https://ВАШ_ЛОГИН.github.io/ВАШ_РЕПО/
   ```

   Статус сборки виден во вкладке **Actions**.

> **Без воркфлоу:** можно собрать локально (`npm install && npm run build`),
> выложить содержимое папки `dist` в ветку `gh-pages` и в Settings → Pages
> выбрать **Deploy from a branch → gh-pages**.

## Установка на Android

1. Откройте ссылку Pages в **Chrome** на телефоне.
2. В шапке игры появится золотая кнопка **«Установить»** — нажмите её
   (или меню Chrome ⋮ → **«Установить приложение» / «Добавить на главный экран»**).
3. На главном экране появится ярлык с кругом энсо. Игра запускается
   в полноэкранном режиме, без браузерной строки, и продолжается с того
   же места — прогресс сохраняется в браузере автоматически.

После первого открытия Chrome кэширует игру, и установленное приложение
обычно работает даже без интернета.

## Что внутри

- **Средний уровень** — генератор с проверкой единственности решения (~35 открытых клеток)
- **Бесконечные подсказки** (кнопка или клавиша `H`)
- **Режим быстрого заполнения** — тап по цифре на панели, затем тапы по пустым клеткам
- **Отмена действий** — кнопка «Отмена», `Ctrl+Z` или `U` (до 300 шагов)
- **Заметки карандашом** (`N`), мягкая подсветка конфликтов — проиграть невозможно
- **Тёмная и светлая темы**, автосохранение партии, прогресс-обруч в шапке
- Клавиатура: `1–9` — цифра, стрелки — движение, `Backspace` — стереть, `Esc` — сброс

## Структура

| Файл | Назначение |
| --- | --- |
| `index.html` | Вся игра: разметка, стили, движок, иконки и PWA-манифест |
| `.github/workflows/deploy.yml` | Автосборка и публикация в GitHub Pages |

Локальная разработка: `npm install`, затем `npm run dev` или просто открыть
`index.html` двойным щелчком — сервер не нужен.
